# DnA Photography Website

A responsive black-and-white photography and videography website for DnA Photography.

## Included
- Multi-section navigation: Home, About, Services, Gallery, Contact
- Responsive layout for desktop, tablet and mobile
- Scroll-reveal animations
- Full-screen image viewer
- Download-original button for each gallery image
- Mobile navigation menu
- Phone and WhatsApp contact buttons
- User-provided DnA Photography logo and portfolio images
- No build tools required

## How to use
Open `index.html` in a browser.

For publishing, upload the entire `DnA_Photography` folder to your hosting service or GitHub Pages.
